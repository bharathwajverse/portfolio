★ Flagship Project · AI Agent

RailCascade

A reinforcement learning benchmark where an AI agent coordinates multiple trains across a 10-node directed graph to minimize cascading delays — with a live Gemini LLM inference agent, FastAPI backend, and Docker deployment.

Problem Railway networks cascade: one delayed train disrupts all. No lightweight RL benchmark existed to test AI coordination strategies under progressive difficulty.
Solution Built a 10-node directed graph RL environment. Agent issues hold/reroute/noop per timestep. Gemini-powered LLM agent + greedy baseline, both exposed via FastAPI/Docker. 6 task levels (easy → extreme).
Outcome Composite score metric (delay_score × arrival_ratio). Real-time canvas dashboard. Cleanly dockerized REST backend. Architecture that mirrors production AI agent infrastructure.
Python FastAPI Gemini API Docker RL Environment REST API Canvas Dashboard

HealthSim

Clinical risk simulator — cardiac, diabetes & stress risk modeling from real biometric inputs. Built under hackathon time pressure. Shipped with WebGL, PDF export, and Supabase sessions.

Problem Doctors lack quick, patient-friendly tools to visualize how lifestyle changes affect clinical risk scores in real time.
Solution Built biometric input → multi-risk model → "What-If" scenario testing matrix. Three.js WebGL spatial interface, Recharts visualization, anonymous Supabase sessions.
Outcome Doctor-friendly jsPDF export, real-time risk recomputation on input change. Shipped in a hackathon window. Proud to demo to actual clinicians.
Next.js 14 React 18 Three.js Supabase Tailwind CSS jsPDF Recharts
