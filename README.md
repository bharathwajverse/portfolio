# Portfolio

Modern AI Engineer Portfolio Website showcasing AI agents, LLM applications, reinforcement learning environments, full-stack projects, and hackathon work. Built with advanced UI design, responsive layouts, and production-style project storytelling.

## Features

- Responsive design for all devices
- Modern UI with dark theme
- Showcases AI/ML projects and hackathon work
- Built with HTML, CSS, and vanilla JavaScript

## Technologies Used

- HTML5
- CSS3 (with custom properties and animations)
- Google Fonts (Plus Jakarta Sans, Inter, Fira Code)

## How to View

Simply open `portfolio-v2.html` in any modern web browser.

## Deployment

This is a static website that can be deployed on any web server or hosting platform like GitHub Pages, Netlify, or Vercel.
